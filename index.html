Topics Studied

Core concepts explored in Data Communication

Communication Models

The Shannon-Weaver model defines communication as a sender encoding a message through a channel to a receiver. Noise can disrupt the signal at any stage, making error control essential in modern systems.

Network Topologies

Network topology defines how devices are physically or logically connected. Common types include Bus, Star, Ring, Mesh, and Hybrid. Star topology is most widely used today due to its fault isolation capabilities.

OSI Model

The OSI (Open Systems Interconnection) model has 7 layers: Physical, Data Link, Network, Transport, Session, Presentation, and Application. Each layer handles a specific communication function, enabling interoperability between different systems.

TCP/IP Protocol

TCP/IP is the foundational protocol suite of the internet. It operates on four layers: Network Access, Internet, Transport, and Application. TCP ensures reliable delivery while IP handles addressing and routing of packets.

Transmission Media

Guided media (twisted pair, coaxial cable, fibre optic) direct signals along a physical path. Unguided media (radio waves, microwaves, infrared) transmit signals through the atmosphere, enabling wireless communication worldwide.

Analog vs Digital

Analog signals are continuous waveforms while digital signals use discrete binary states (0 and 1). Digital communication dominates modern systems due to its superior noise resistance, compression efficiency, and compatibility with computers.

Wireless Communication

Wireless technologies include Wi-Fi (IEEE 802.11), Bluetooth, 4G/5G cellular networks, and satellite communication. 5G networks promise ultra-low latency and speeds up to 20 Gbps, enabling IoT, autonomous vehicles, and smart cities.

Error Detection

Error detection techniques identify corrupted data during transmission. Parity bits add a single check bit; checksums validate data blocks; CRC (Cyclic Redundancy Check) uses polynomial division for highly reliable detection in networking protocols.

Telegraph Systems

The electrical telegraph, invented in the 1830s, was the first long-distance digital communication system. It used Morse code — a series of dots and dashes representing letters — transmitted as electrical pulses over copper wire lines.

How the Telegraph Works

Pressing the telegraph key at the sender's station completes an electrical circuit. Current flows from the battery through the wire to the electromagnet at the receiving station, which attracts an iron armature and produces a clicking sound on the sounder.

Releasing the key breaks the circuit, stopping the current and releasing the armature. By varying the duration of key presses, operators encode messages using Morse Code.
